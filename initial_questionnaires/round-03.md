gurgenBudget — Questop, Round 3

01. How should you add or edit Base and Flex items — one at a time via a simple "+ Add" (tap an item to edit it), or a bulk-entry table where you fill several rows before saving?
Answer: One at a time via "+ Add" — tap an existing item to edit it.

02. Does the Wishlist need any ordering (drag to reorder, "top of list = most wanted"), or is a flat, unordered list fine?
Answer: Flat and unordered — items just show in whatever order they were added.

03. Should the app block zero or negative amounts on items, or allow anything as long as it's a number?
Answer: Allow anything — no validation beyond "must be a number."

04. First time you sign in, should there be a guided setup flow (walks you through Buffer, then Base items), or does it just drop you into an empty dashboard?
Answer: Empty dashboard — no formal onboarding.

05. Is there a visible Settings screen (where the Buffer lives, alongside things like sign-out), or is the Buffer edited inline wherever it's shown, with no dedicated screen?
Answer: A simple, visible Settings screen.

06. In History, how do you move between months — a simple back/forward arrow one month at a time, or a direct picker to jump to any month?
Answer: A direct picker (calendar/dropdown) to jump to any month.

07. Since items can move between Flex Spend and Wishlist, should adding a new one go through one shared entry point with a toggle for which list it lands in, or should each list have its own separate "add" button?
Answer: One shared entry point with a Flex Spend / Wishlist toggle.

08. Last one — should the project scaffold (Vite + React + Firebase + GitHub Pages deploy) get set up now, in parallel with any remaining Questop rounds, or only after Questop fully wraps?
Answer: Hold off until Questop wraps.
